# Licence and attribution inventory

LIFEOS's own source code has **no licence chosen yet** (`"license": "UNLICENSED"` in `package.json`): pick one before
publishing the repository for others to reuse.

## How third-party work is used

- Open-source code is used **only as unmodified npm dependencies**. No source files were copied from other
  repositories into this codebase, so there are no per-file attribution headers to maintain.
- Every shipped dependency is under a permissive licence (MIT, ISC, Apache-2.0, BSD-3-Clause, or the dual
  MPL-2.0/Apache-2.0 of DOMPurify, used under Apache-2.0). **No GPL or AGPL code is included.** Several
  well-known projects in this space (Logseq, AppFlowy, Plane, Trilium, SiYuan, Firefly III — AGPL-3.0; Loop Habit
  Tracker — GPL-3.0) were reviewed for ideas only and none of their code was used; see `docs/RESEARCH.md`.
- Fonts are self-hosted from Fontsource packages: **Geist** and **Geist Mono** (SIL Open Font License 1.1, Vercel) and
  **Space Grotesk** (SIL Open Font License 1.1, Florian Karsten). The OFL allows bundling; the font files are not
  modified or sold on their own.
- Icons are **Lucide** (ISC licence), imported one by one from `lucide-react`.
- The 3D workspace uses **procedural geometry only**. There are no downloaded models, textures, HDRIs or audio files, so
  there are no asset licences to track. Ambient sounds are synthesised in the browser with the Web Audio API.
- The spaced-repetition scheduler is **ts-fsrs** (MIT), an implementation of the FSRS algorithm.
- Apache-2.0 dependencies (Prisma, Dexie, DOMPurify, TypeScript, Playwright) carry their own `LICENSE`/`NOTICE` files
  inside `node_modules`; they are redistributed unmodified.
